# R47 fixed-prediction error inventory

This directory records the complete current-R38 error review of PR133's
candidate, prepared after the PR134 annotation review on 27 November 2026 HKT.
It contains no weights, photographs or PDFs.

- `error-index.json`: all 123 case cards, exact coordinates and original hashes.
- `verification.json`: archive replay, case coverage, PDF hash and render QA.

See [the review and reproduction guide](../../../docs/front-error-review-r47.md).
The PDF is delivered separately in the conversation and regenerated by
`scripts/export_front_error_review_r47.py`.

No fresh training or inference was performed. Current R38 labels remain
unchanged. Formal duplicates are a subset of all unmatched predictions;
“other unmatched” is not automatically physical background.
