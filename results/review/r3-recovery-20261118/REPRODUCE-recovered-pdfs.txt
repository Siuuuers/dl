Run command (replace the workspace prefix with the restored workspace root):

python /path/to/workspace/dl/scripts/build_recovered_review_pdfs.py \
  --workspace /path/to/workspace \
  --current-labels /path/to/workspace/dl/data/reviews/fronts-2026-11-18/labels \
  --current-manifest /path/to/workspace/dl/data/reviews/fronts-2026-11-18/manifest.json

Arguments

--workspace is the root containing the input layout below. It defaults to the
current working directory. The script itself may be stored elsewhere.
--current-labels selects the final authoritative labels directory. Supply it
for this delivered revision; omitting it uses the script's provisional row52
fallback instead of the authoritative final token formatting.
--current-manifest records the current review-manifest SHA256 in the audit.
It defaults to manifest.json beside --current-labels. This argument changes
provenance metadata only; it does not change PDF geometry or training inputs.
