# Bounded annotation review after the controlled training-label experiment

## Result and scope

Eight diagnostic regions from seven original photographs were inspected against the [visible-front definition](../annotation-definition.md). The review supports retaining the selected annotations in seven regions and preserving an explicit corner-availability uncertainty in the remaining thin top-border region. **No annotation, model, prediction, threshold or historical score changed.** The structured decisions are in [review-decisions.json](evidence/annotation-review-r65/review-decisions.json).

The photographs support specific decisions about front ownership, visible extent and unavailable corners. They also reveal a material scope distinction: the reviewed benchmark contains inherited, explicitly requested exclusions, including a visible partial front. Consequently, an unmatched prediction is an extra under the named reference; that status alone does not establish that it depicts physical background.

This is a bounded, agent-assisted review of deliberately selected difficult regions, with one ordinary control. It is not a random sample, an exhaustive review of the 20 development photographs, an independently blinded human study, or a new test set. The case list and numeric reference coordinates were known before inspection. The sequence was nevertheless kept explicit: inspect the unmarked full photograph and crop, save the physical observations, then reveal reference and prediction overlays. [Raw observations](evidence/annotation-review-r65/raw-observations.json) were saved before the comparison panels were created.

Prediction panels use the returned controlled experiment's `original_labels` and `reviewed_labels` training arms, each with the same two-view rule. The evaluator uses box IoU 0.50 and the existing confidence settings. Reference panels show the untouched supplied reference, the earlier frozen reference and the later reviewed reference. Row numbers belong to their named reference and image; equal row numbers across versions are not assumed to identify the same cassette.

## A concrete reference-dependent match

Case 03 separates corner location from box definition. The corresponding supplied/frozen row has box `[569.40,90.06,679.28,126.07]`; the reviewed row has box approximately `[586.38,89.00,682.00,114.00]`. Both keep the same two lower-corner coordinates. On the unmarked photograph, the older box extends into the rack below and to the left of the selected white front. The larger box is therefore not simply a different decimal rounding of the same visible extent.

The same retained prediction can change status when only the reference changes:

| Fixed prediction from the controlled experiment | IoU with supplied `R011` | IoU with reviewed `R010` |
| --- | ---: | ---: |
| Original-label arm `P016` | 0.5973 | 0.5895 |
| Reviewed-label arm `P018` | 0.4455 | 0.6837 |

At IoU 0.50, the reviewed-label prediction fails against the supplied box and succeeds against the reviewed box. This case gives photograph-based support for one reference revision and explains the direction of one measured difference. It does not establish the physical accuracy of every reviewed row or prove that the complete model is better on future photographs. Exact boxes, points, prediction indices, match status and overlaps are preserved in [comparison-context.json](evidence/annotation-review-r65/comparison-context.json).

## The inherited exclusion must remain visible in the evidence

The lower partial in case 04 is especially useful because it prevents equating all extras with nonexistent objects. The [R38 record](../front-review-r38.md) explicitly removed five R37 rows by user instruction. Its former `new_000009:52` had box `[600,490,615,504]` and one observed corner near `(601,502)`. That record explicitly acknowledges a visible partial front and describes the removal as a change to the scored target population. The exact historical operation and source hash are copied into [legacy-exclusion.json](evidence/annotation-review-r65/legacy-exclusion.json).

The lower white fragment was visible during the new image review before the historical explanation was consulted. This observation is consistent with the recorded reason for preserving a scope exception. This review keeps the earlier exclusion and every historical reference unchanged. The general definition still says to retain identifiable partial fronts, while this frozen evaluation inventory carries its explicit legacy exceptions. Future evaluation or review tooling should display those exceptions so an operator does not mistake a deliberate exclusion for an annotation omission or a physically verified negative example.

Deleting a visible front from a reference also does not create an implemented ignore region. The current evaluator still treats an unmatched retained output as an extra. Introducing an ignore mechanism would change the evaluation contract and requires a separately named protocol; it is not part of this review.

## What the duplicate regions establish

The new experiment's duplicate ledger identifies repeated hypotheses on several partial-front bands in cases 04 and 05 and on the narrow top-border front in case 08. In case 08, matched `P053` and duplicate `P055` cover the same small fragment. Their predicted-box IoU is approximately 0.6997, while `P055` overlaps the reference by approximately 0.8274. These are different comparisons: prediction-to-prediction overlap governs suppression, whereas prediction-to-reference overlap governs scoring. [The returned duplicate ledger](evidence/training-label-return/reviewed-duplicate-cases.json) preserves the exact assignments.

The raw photographs support checking suppression on these individual bands. They do not support merging all nearby partials: the visible horizontal seams identify several neighbouring fronts. A lower suppression threshold must therefore be evaluated for both duplicate removal and lost neighbouring matches. Selecting a threshold because it removes this one attractive example would reuse the development evidence for tuning, not provide a fresh test of improvement.

Cases 01 and 06 provide a complementary warning about terminology. Both arms already produce outputs on the selected regions. Their changes in matched status come from how their boxes overlap the reference. The evidence supports “recovered reference match”; it does not demonstrate that the original-label model produced no visual response to the front.

## Research basis and the next reusable review

The existing annotation literature supplies a small review procedure rather than an automatic answer to which cassette label is correct:

- [Extreme Clicking for Efficient Object Annotation](https://arxiv.org/abs/1708.02750) asks annotators to identify four object extrema. Here that idea is used to inspect the four sides of a visible-front box one at a time; it does not establish a cassette contour or justify hidden extent.
- The [CityPersons annotation format](https://github.com/cvgroup-njust/CityPersons/blob/master/annotations/README.txt) distinguishes full and visible boxes. This motivates stating which extent the cassette task uses. It does not transfer the pedestrian dataset's amodal targets to these fronts.
- [Noise-Aware Evaluation of Object Detectors](https://openaccess.thecvf.com/content/WACV2025/html/Llerena_Noise-Aware_Evaluation_of_Object_Detectors_WACV_2025_paper.html) studies how annotation discrepancies affect detector evaluation, including restrictive IoU criteria. Here that motivates reporting sensitivity to the reference and checking the underlying photographs. We have not implemented its alternative metrics or inferred that any reference is correct because it favours a model.

A useful next notebook is a CPU review packet, not another inference run. Its four cells can verify pinned source/archives and original image hashes, generate a raw packet and blank response form, reveal separately stored reference/prediction panels, and export a provenance-preserving review result. Raw judgments should record instance identity, visible extrema, each corner's availability, alternatives and uncertainty before any model result is shown. Reference rows must retain version-qualified identities and an explicit legacy-exclusion field. The notebook must not write dataset labels automatically.

For actual repeatability evidence, an independent human reviewer should work from the raw photographs without the previous coordinates or model outcomes. A delayed repeat by the same reviewer measures within-reviewer repeatability and must be named accordingly. Compare instance inclusion and corner availability separately from box-side displacement and corner distance. Do not compute coordinate agreement across rows that may refer to different physical fronts.

The present eight cases can calibrate that procedure, but they cannot settle the entire benchmark ranking. A stronger adjudication would review all reference-disagreement regions and sweep the full photographs for omitted or duplicated instances under the declared scope, preserve unresolved alternatives, then rescore the unchanged predictions. A separately captured, frozen test set would address generalization. Neither an unperformed human review nor an unavailable new capture is claimed as completed here.

## Reproducibility

The original PNGs were downloaded from the existing asset commit and each matched its manifest SHA-256 and 1280-by-720 dimensions. The fixed three-reference archive and the returned training-label evidence ZIP passed their member inventories. Saved per-image scores for both shown training arms were replayed against the unchanged scorer on the seven selected images. The 24 main panels were reproduced byte for byte using the included [renderer](evidence/annotation-review-r65/render_panels.py); the extra separated border comparison gives 25 PNGs in total. The [evidence README](evidence/annotation-review-r65/README.md), provenance, review records and inventory retain the exact inputs and outputs.

This verification establishes file identity, display construction and score replay. It does not turn the assistant's visual judgment into independent human truth, estimate human annotation precision, or establish a population-wide error rate.
