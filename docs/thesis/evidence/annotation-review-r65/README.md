# Bounded photo-review evidence

Completed agent-assisted review of **eight regions in seven photographs** after the controlled training-label return. Seven selected annotations were retained; the thin top-border case remains explicitly uncertain. **Zero label changes.** The [review note](../../annotation-review-r65.md) explains the physical observations, reference dependence, duplicate clusters and inherited scope exception.

## Contents and viewing order

1. `case-01-raw.png` through `case-08-raw.png` show unmarked crops at three-times nearest-neighbour enlargement. Original full frames were also inspected. Crop bounds and original image hashes are recorded in the JSON files.
2. `raw-observations.json` preserves judgments saved before any comparison panel was generated or viewed. Case selection and numeric target coordinates were already known, so this is not a blinded human study.
3. The eight `*-references.png` files reveal supplied, frozen and reviewed references in separate panels. The eight `*-predictions.png` files reveal the returned original-label and reviewed-label training arms using the two-view rule. In prediction panels `M` means matched, `D` duplicate extra and `E` other extra under the reviewed reference's fixed evaluator.
4. `case-08-target-comparison.png` separates the thin reviewed `R012` front, matched prediction `P053` and duplicate `P055` so dense overlapping labels cannot hide their geometry.
5. `comparison-context.json` contains exact version-qualified rows, boxes, points, prediction indices, confidences and saved match identities for the displayed regions. No cross-version row-index correspondence is assumed. A zero maximum overlap has no nearest-reference identity.
6. `review-decisions.json` records the post-overlay decisions and uncertainties. `legacy-exclusion.json` copies the exact former R37 `new_000009:52` exclusion operation, including its source hash and visible-front acknowledgement.
7. `input-provenance.json`, `review-validation.json` and `inventory.json` preserve acquisition, verification and output identities. The inventory excludes itself.

The seven original PNGs are already repository assets at the manifest-pinned commit `ea4ac955f2dfaf1add24c243599715f802eb41a7`; they are not duplicated here. Their complete pinned URLs, byte lengths and SHA-256 values appear in `input-provenance.json`. All seven matched those identities. Both input evidence ZIPs passed complete member-inventory checks, and the unchanged scorer reproduced the saved per-image records for both displayed arms on all seven photographs.

## Reproduce the panels

The renderer needs Python, Pillow and the system DejaVu Sans font at `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`. Put the seven verified original files named `new_*.png` in one directory, then run from the repository root:

```bash
python docs/thesis/evidence/annotation-review-r65/render_panels.py \
  --image-dir /absolute/path/to/originals \
  --output /absolute/path/to/recreated-panels
```

It verifies every original's bytes, SHA-256 and dimensions before writing 25 PNGs to the chosen output directory. The included numerical context supplies the displayed annotations and predictions; it does not retrain or rerun a model. All 24 main PNGs were reproduced byte for byte with this renderer, and the separated border comparison was generated by the same code. The validation receipt records the actual rendering environment.

## Limits

Selection was purposive and used returned diagnostic outcomes, including a single ordinary control. These eight regions cannot estimate a population annotation-error rate or certify the full development inventory. Soft boundaries were not converted into spurious subpixel certainty. The study did not measure human repeatability, add an independent human reference, or collect new test photographs.

The general visible-front policy and the frozen reviewed inventory have documented legacy differences. A visible lower partial in case04 remains excluded by the earlier user-directed R38 decision. No exclusion was reversed, no ignore-region mechanism was added, and no score or label file was changed. Independent human raw-image review, or a clearly named delayed repeat by the same reviewer, remains a useful future check.
