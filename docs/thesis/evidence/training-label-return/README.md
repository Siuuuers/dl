# Independent audit of the controlled training-label return

This folder preserves the analysis of [PR158](https://github.com/Siuuuers/dl/pull/158) at result commit [`6bde3b7a759604d605965d468e6102bf99bf7946`](https://github.com/Siuuuers/dl/tree/6bde3b7a759604d605965d468e6102bf99bf7946/results/l4/baomai-training-label-comparison-r61-l4-001). The exact execution source is [`acaf5d4b4043583fdd81f5ea848b3a6a68ada728`](https://github.com/Siuuuers/dl/tree/acaf5d4b4043583fdd81f5ea848b3a6a68ada728). The compact original return and model wrappers remain in that result commit; they are not duplicated here.

## Findings and scope

At the common two-view setting against the reviewed reference, original-label versus reviewed-label fine-tuning gives **47 versus 15 misses, 85 versus 51 extras, 6 versus 13 duplicates, 541 versus 572 complete pairs within five pixels, and 566 versus 583 within ten**. Both older references favour the original-label arm. [The result note](../../training-label-results.md) explains the intervention, paired changes, duplicate tradeoff and causal limits.

The byte checks, final training receipts and exact saved-output replay pass. One auxiliary progress log has a four-byte `arm\n` prefix and is not valid JSON; its remaining bytes exactly equal the valid final receipt. The original member is preserved and the observation is recorded in `audit.json`. This audit neither repairs that archive member nor repeats training or neural inference.

Dataset/output paths are the only differing training settings. The independent matcher checks 240 scored image combinations and all complete-pair states.

## Reproduction

Have the two immutable commits above available in a Git clone. Place these six result members in a separate directory: `return-manifest.json`, `baomai-training-label-comparison-r61-results.zip`, and the two `.pt.part00.zip` / `.pt.part01.zip` wrappers for each of `original_labels-last` and `reviewed_labels-last`. Keep the returned wrappers intact.

```bash
python docs/thesis/evidence/training-label-return/verify_return.py \
  --repo /path/to/dl \
  --return-dir /path/to/pr158-return \
  --output-dir /path/to/replayed-audit
```

The script validates the original result bytes, extracts only source/data into a temporary directory, imports the verified pinned evaluator, and recreates `audit.json`, `measurement-replayed.json`, `per-image.csv`, `paired-detection-cases.json` and `reviewed-duplicate-cases.json`. It changes no Git state, annotation, checkpoint or inference setting. The inspection priority list is a separate, explicitly selected diagnostic artifact and is not generated by the replay.
