# Final Year Project I report requirements

The report is for an undergraduate Final Year Project I in the Department of Electronic Engineering, followed by Project II next semester. It explains the computer-vision work for an unfamiliar reader without adding an artificial electronics theme. The user requested omission of Acknowledgements. No institution-specific cover template, word limit, or page limit has been supplied.

## Required structure

| Requirement | Current report |
| --- | --- |
| Abstract of 150–300 words | Section 1; 231 words on objectives, work completed, main results, and next phase |
| Acknowledgements | Omitted at the user's request |
| Table of Contents | Section 2; every section and subsection, decimal numbering, and verified DOCX page numbers |
| Introduction | Section 3; task, relevant published work, aim, and working requirements |
| Background | Section 4; image coordinates, annotations, matching, corner errors, and accepted outputs |
| Methodology and Implementation | Section 5; images, models, controlled changes, and measurement procedures |
| Simulation Results | Section 6; completed controlled digital masking experiment |
| Experimental Results | Section 7; annotation, training, image processing, combination, pair acceptance, and crop-feasibility results |
| Discussions | Section 8; findings, evidence limits, pending reflection comparison, and Project II plan |
| Conclusions | Section 9; supported conclusions and next uses of the evaluation procedure |
| References | Section 10; 29 IEEE references in first-citation order |
| Appendices | Section 11; additional annotation comparisons and reproduction procedure |

## Presentation and evidence

- All 38 sections and subsections receive decimal numbers and contents entries.
- Eight major equations are numbered and stored as editable Word equations.
- Four figures and nine tables have descriptive numbered captions.
- Physical units are metric; pixel distances describe image coordinates.
- Published results support the choice of methods and hypotheses. Cassette results come from the project's recorded experiments.
- Terms and abbreviations are introduced before use. Descriptive experiment and reference names replace internal revision codes in report prose, tables, and figure labels.
- Source identifiers, hashes, and repository names needed for reproduction appear in the separate source map and evidence records.
- Completed experiments, analyses of saved predictions, and pending model results are distinguished. Material limits are explained together in the discussion.

The Word report uses a simple academic layout: Letter portrait, 25 mm margins, Times New Roman, black headings, and numbered pages. An institution template can be applied later.
